關於本作

你叫高松燈。但你是一隻企鵝。

你站在 Live House 屋頂,看著 8 個人準備散場。你不知道「CRYCHIC」是什麼,不知道「主唱」是什麼,不知道為什麼大家看著你。你只知道一件事:你想唱歌。

純文字音樂懸疑劇,玩家 = 企鵝版高松燈,角色全部用原作真名。

技術棧

  • • HTML5 + Vanilla JS,無引擎
  • • 純 SVG 企鵝立繭(0 圖片依賴,0 版權風險)
  • • 8 首歌的歌名揭示機制
  • • 繁簡切換
  • • 完全靜態,可離線玩

本地運行

如果你想本地開發:

git clone git@github.com:yip-lgtm/ki7409-game-jam-202608.git
cd ki7409-game-jam-202608
cd src
python3 -m http.server 8000
# 瀏覽器打開 http://localhost:8000

操作

  • • SPACE / Enter / 點擊 — 推進文本
  • • 點擊選項按鈕 — 選擇分支
  • • 點擊右上「繁 / 简」— 切換語言
  • • 標題屏點擊企鵝 — 切換企鵝表情
