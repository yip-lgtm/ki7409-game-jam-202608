# Game Concept: 迷茫即是前進 — 湊企鵝篇

*Created: 2026-08-01*
*Status: Draft v0.1 (1-month jam, solo)*
*IP: BanG Dream! It's MyGO!!!!! / Ave Mujica(同人二次創作)*

---

## Elevator Pitch

> 一部以 CRYCHIC 解散之夜為錨點的純文字懸疑劇。
> 玩家以「路人視角」旁觀 9 名角色的崩潰與覺醒,
> 唯一完整路線是「湊企鵝(高松燈同位體)」的救贖。
> 90 分鐘閱讀,1 個結局,3 個真相片段,繁簡雙語。

## Core Fantasy

> 「你無法拯救任何人,但你可以**在場**。」
> 在原作最痛的場景裡,作為一個不在原作的人,讓 9 個角色知道
> 「有人看到了」——僅此而已。

## Unique Hook

> **「高松燈是企鵝。」**
> 設定上:CRYCHIC 的主唱不是人類,是「在《公主連結》世界迷失後墜入 BanG Dream 世界
> 的迷途企鵝」。她用歌聲召喚同伴,被召喚的同伴因此相信她。
> 燈 = 湊企鵝(同位體,平行世界邏輯,非直接 IP crossover)。
> → 1 月份產能內能做、避免版權警告、增加 B 站二創話題性(「企鵝燈」已是同人圈梗)。

## Player Experience (MDA)

| Aesthetic | Priority | How We Deliver It |
| ---- | ---- | ---- |
| **Narrative** | 1 | 90 分鐘純文本,單一錨點多視角 |
| **Fellowship** | 2 | 9 角色場景互動,觀眾見證群像關係 |
| **Discovery** | 3 | 二創彩蛋 + 隱藏 CG + 二創曲解鎖 |
| **Sensation** | 4 | BGM 切換 + 文字節奏 |
| 其餘 | N/A | 純文字遊戲不需要 |

### Core Mechanics

1. **打字機文本** — `setInterval` 一字一字 render,空格/Enter 加速
2. **立繪切換** — `<img>` src 切換 + 淡入淡出
3. **BGM 切換** — Web Audio + 場景觸發
4. **選項分叉** — 2-4 個選項,影響下一 scene id(不影響結局)
5. **視角切換** — 場景 metadata 標記 POV,UI 顯示當前視角角色
6. **回憶片段** — 時間軸錨點 + 視覺濾鏡(灰色 / 紅色)
7. **二創彩蛋** — 通關後解鎖,玩家主動觸發

### 不做

- ❌ Save/Load(90 分鐘不需要)
- ❌ Backlog(同上)
- ❌ 語音(同人無 CV 版權)
- ❌ 多結局(本路線固定 1 結局)
- ❌ 美術立繪原創(用官方立繪 + 文字描述彌補)
- ❌ 商業元素

## Game Pillars

### Pillar 1:「語感即美術」
> 沒有立繪的細節 = 沒有 CV 的語氣 = 文字必須自己撐起畫面。
> 一句台詞只做一件事:傳達情緒 / 推進劇情 / 製造張力。

*Design test*: 任何一句台詞如果刪掉不影響玩家理解情緒 → 刪掉。

### Pillar 2:「旁觀者不等於冷漠」
> 玩家角色(路人)全程無對話,只通過**觸發回憶片段**參與劇情。
> 路人不是旁觀,是「在場的沉默者」。

*Design test*: 路人觸發回憶時,UI 必須有視覺提示(灰階 / 失真),讓玩家感覺自己「打開了角色的門」。

### Pillar 3:「三句話建立角色」
> 同人遊戲的觀眾**已經知道角色**。台詞要服務粉絲的「我懂她」,
> 不是服務新觀眾的「她是誰」。

*Design test*: 每個角色首次開口必須是粉絲能背的台詞 / 名場面相關變體,不是新寫的「介紹性台詞」。

### Anti-Pillars

- **NOT 機制花巧**:這是純文字遊戲,加 QTE / 小遊戲 = 偏離 Pillar 1
- **NOT 解釋原作**:預設觀眾看過動畫,不解釋 CRYCHIC 是什麼
- **NOT 強行歡樂**:原作基調沉重,不走搞笑同人路線(企鵝設定是反差萌,不是吐槽)

## 路線設計(本 PR 只做這條,其它 8 條留空檔)

### Common Route(30 分鐘)
- 場景:Live House 屋頂,CRYCHIC 解散前一晚
- POV:輪轉 — 燈 → 爽世 → 立希 → 愛音 → 祥子
- 玩家選擇:「走向誰」(5 個分支入口,每個 1 場景)
- 結尾:祥子電話響起,音樂戛然而止 → 切黑屏 → 「翌日」

### 湊企鵝(高松燈同位體)線(60 分鐘)
- 前提:玩家在 Common 結尾選擇「跟著那個奇怪的歌聲走」
- POV 鎖定:燈 / 祥子 雙視角交替
- 核心衝突:燈(企鵝)不知道自己為什麼會在這裡,只想唱歌;祥子因為家庭變故無法繼續 CRYCHIC
- 結局:燈唱完最後一首歌(動畫 ED《春日影》變奏),企鵝化消散,留下祥子一個人面對自己
- **不救贖**,不和解,只是「在場」

### 其它 8 角色(只出場,不開路線)
- 爽世 / 立希 / 愛音 / 睦 / 初華 / 海鈴 / 若麥 — Common 結尾彩蛋
- 二週目後在標題畫面看到「?????」,點擊解鎖其餘 8 個角色 CG

## MVP Definition(本 PR 範圍)

**核心假設**:「粉絲願意花 90 分鐘讀一個固定結局的純文字遊戲,只要角色語感對。」

**Required for MVP**:
1. ✅ 打字機 + 選項 + 場景切換核心引擎
2. ✅ 繁簡切換
3. ✅ Common Route 完整 30 分鐘劇本
4. ⏳ 湊企鵝線 60 分鐘劇本(本 PR 寫 ~30 分鐘 + 佔位,後續 PR 補完)
5. ✅ 標題畫面 + 通關畫面
6. ⏳ BGM 系統(本 PR 用靜音 + 1 首 BGM,後續加)
7. ⏳ 二創彩蛋(本 PR 留接口,不做)

**Explicitly NOT in MVP**:
- 其它 8 條路線
- Save/Load
- Backlog
- 原創立繪 / 語音
- 商業包裝

## 風險

| 類型 | 風險 | 緩解 |
| --- | --- | --- |
| 版權 | BanG Dream 是 Bushiroad IP,同人不商業 OK,商用必被告 | 開源、零收費、標註同人 |
| 版權 | 公主連結企鵝是 Cygames IP,直接 crossover 有風險 | **設定為平行世界同位體,非直接 crossover**;企鵝外觀不畫出來 |

| 產能 | 1 人 1 月寫 3 萬字 + 引擎 = 緊 | 砍 Common Route 到 20 分鐘,燈線到 50 分鐘,留 10 分鐘緩衝 |
