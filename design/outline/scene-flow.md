# 場景流程大綱 — 迷茫即是前進 湊企鵝篇

*總時長 90 分鐘(20 + 60 + 10)*
*Common Route → 燈線 → 尾聲*

---

## Part 0: Title & Boot(1 分鐘)

### Scene 0.1: 標題畫面
- 背景:夜空 + 月亮 + 屋頂輪廓(無立繪)
- 文字動畫:標題從上往下浮現
- 按鈕:開始 / 設定 / 語言切換(繁/簡)
- 背景音:極輕的鋼琴單音,Loop

---

## Part 1: Common Route(20 分鐘,5 場景)

### Scene 1.1: 「屋頂」(3 分鐘)
**POV**:旁觀者
**背景**:Live House 屋頂,夜,月光
**觸發**:旁觀者爬上樓梯,看到一群女孩在排練

**內容**:
- 旁觀者無對白
- 視角掃過 5 個身影:燈(企鵝輪廓)、爽世(在調音)、立希(在敲鼓)、愛音(在旁邊不知所措)、祥子(在窗邊打電話)
- 對話片段(無選項,純文本滾動):
  - 爽世:「(對燈)再唱一次。」
  - 燈:「好。」
  - 立希:「(鼓點)三、二、一——」

**UI**:屋頂場景圖 + 文字框(底部)+ 視角指示器(左上「旁觀者」)

**結局**:選項彈出
- → 1.2A: 走向燈(企鵝輪廓)
- → 1.2B: 走向爽世
- → 1.2C: 走向立希
- → 1.2D: 走向愛音
- → 1.2E: 走向祥子的電話

---

### Scene 1.2A: 燈的回憶(3 分鐘)
**POV**:燈(透過旁觀者觸發的回憶)
**視覺**:灰階 + 失真(路人視角的特徵)
**觸發**:旁觀者走向燈,燈唱了一句歌,旁觀者的視角「被拉進去」

**內容**:
- 回憶 1:燈在另一個世界(無描述,只有「光很亮、聲音很多、不孤單」)
- 回憶 2:燈在這個世界(只有「人很少、聲音很遠、想回去」)
- 對話:
  - 燈:「(唱歌)【……迷失也無妨。迷失著,也要前進……】」
  - 旁觀者:無對白
  - 視角回到屋頂,燈的影子是企鵝輪廓

**結局**:選項
- → 1.3 集結(必經,所有路徑合流)

---

### Scene 1.2B-1.2E: 其它角色回憶(各 2-3 分鐘)
- 1.2B 爽世:她的回憶是「CRYCHIC 第一次演出」(彩色 → 黑白的轉場)
- 1.2C 立希:她的回憶是「鼓組」(只有鼓點,沒有畫面)
- 1.2D 愛音:她的回憶是「被爽世邀請的那天」(但爽世的笑臉失焦)
- 1.2E 祥子:她的回憶是「電話」(電話響,但沒接)

**合流**:所有路徑回到 Scene 1.3

---

### Scene 1.3: 集結(2 分鐘)
**POV**:旁觀者
**觸發**:5 個人都注意到旁觀者的存在(短暫)
**內容**:
- 立希:「(對旁觀者)你誰啊?」
- 爽世:「(小聲)別嚇人。」
- 燈:「(對旁觀者,歪頭)你……聽見了?」
- 祥子:「(掛電話,掃一眼)無所謂。」
- 旁觀者:無對白,但被 5 雙眼睛注視 → 螢幕輕微震動 + 灰階閃爍

**結局**:選項
- → 1.4 解散(自動觸發,無選項)

---

### Scene 1.4: 解散(5 分鐘,NO RETURN)
**POV**:祥子
**觸發**:祥子走到場中央
**內容**:
- 祥子:「CRYCHIC 的排練,到這裡。」
- 爽世:「(站起來)等——」
- 祥子:「我說,結束了。」
- 燈:「(停止唱歌)……啊。」
- 立希:「(放下鼓棒)早該如此。」
- 愛音:「(無所適從)那個……我是不是該走?」
- 祥子:「(對睦)你跟我走。我們有別的事要做。」
- 睦:「(點頭)……嗯。」
- 睦轉身,經過燈時,兩人對視
- 燈:「(小聲)你也是嗎?」
- 睦:「(長沉默)……啊。」(不回答)
- 祥子 + 睦離開
- 爽世追兩步,停下
- 燈:「(對剩下的三人)……我應該走嗎?」
- 立希:「(不回答)」
- 愛音:「(小聲)我……我留下來可以嗎?」

**結局**:畫面緩慢淡黑,BGM 漸弱 → 文字浮現:「翌日」

**選項**(必須選一個,進入 Part 2):
- → 2.1: 跟著燈的視角(企鵝輪廓)走
- → 2.1: 跟著爽世的視角走
- → 2.1: 留在原地,等天亮

**注**:三個選項都進入 2.1,但 POV 鎖定不同。本路線只實作「跟著燈」。

---

## Part 2: 湊企鵝線(60 分鐘,8 場景)

### Scene 2.1: 「那個歌聲」(5 分鐘)
**POV**:燈
**背景**:翌日放學,燈在 Live House 後巷
**內容**:
- 燈:「昨晚……她們都走了。但是我還能聽見那個歌。」
- 旁觀者跟著燈的視角,看到燈在找「那個歌聲」
- 環境描寫:後巷 / 屋頂 / 月亮
- 燈開始唱歌(打字機):【那個歌……在這裡嗎?】
- 突然,旁觀者腳步聲 → 燈轉頭

**選項**:
- → 2.2: 燈走向旁觀者(企鵝直覺,她不害怕陌生人)
- → 2.2: 燈跑走(企鵝逃跑)

---

### Scene 2.2: 「你是誰」(8 分鐘)
**POV**:雙視角(燈 / 旁觀者交替)
**內容**:
- 燈走近旁觀者,繞一圈
- 燈:「你的影子……不是人嗎?」
- 旁觀者:無對白(但被看見)
- 燈:「(歪頭)你不回答也沒關係。我只是想說……你的影子,看起來很累。」
- 旁觀者視角(灰階閃爍):觸發旁觀者的回憶
- 旁觀者回憶 1:昨晚屋頂
- 旁觀者回憶 2:為什麼爬上樓梯(原因留白)
- 燈:「你在這裡,是要找我嗎?」
- 燈伸出手

**選項**:
- → 2.3: 握住(企鵝接受)
- → 2.3: 不握(企鵝困惑但不生氣)

---

### Scene 2.3: 「MyGO 之前」(10 分鐘)
**POV**:雙視角
**背景**:翌日 Live House 屋頂
**內容**:
- 旁觀者跟著燈回到屋頂
- 燈:「昨晚,她們在這裡排練。CRYCHIC。」
- 旁觀者:無對白
- 燈:「(唱歌)【……這首歌是她們的。但我唱著唱著,它變成我的了。】」
- 燈:「(停下)但是……我的歌聲召喚了她們。所以解散……是我的錯嗎?」
- 旁觀者視角:觸發「CRYCHIC 第一次演出」回憶
- 回憶中:爽世的笑臉,立希的鼓,祥子在彈鍵盤,睦在彈吉他,燈在中間唱歌
- 回憶結束,燈:「(對旁觀者)你看到了嗎?她們那時候……是快樂的。」
- 燈:「現在不快樂了。為什麼?」

**選項**:
- → 2.4: 燈決定去找祥子(因為祥子是「最快樂」的那個)
- → 2.4: 燈決定留在屋頂(她不知道怎麼「找」)

---

### Scene 2.4: 「祥子的家」(8 分鐘)
**POV**:祥子(透過旁觀者)
**視覺**:失真更重
**觸發**:燈帶旁觀者去祥子的家
**內容**:
- 祥子家:大,但空
- 祥子:「(開門)你怎麼知道這裡?」
- 燈:「我聽見你的歌。」
- 祥子:「我沒唱歌。」
- 燈:「你心裡有。在哭。」
- 祥子:「(沉默)……進來。」
- 屋內:鍵盤,沒人彈;電話,響了三次,祥子都沒接
- 燈:「(看著鍵盤)這是你的位置嗎?」
- 祥子:「曾經是。」
- 燈:「(觸碰琴鍵)……我可以唱嗎?」
- 祥子:「(長時間沉默)隨便你。」

**選項**:
- → 2.5: 燈唱(企鵝的歌聲,和祥子的家形成對比)
- → 2.5: 燈不唱(她感受到祥子的拒絕)

---

### Scene 2.5: 「春日影(變奏)」(12 分鐘)
**POV**:雙視角,最後切回旁觀者
**視覺**:彩色(全劇唯一彩色段落)
**內容**:
- 燈開始唱【春日影】(打字機 + 玩家節奏提示,空格加速)
- 歌詞變奏:原版是「向前 向前 邁出步伐」,這版是「迷失 迷失 但仍前進」
- 祥子的回憶閃回(彩色):CRYCHIC 演出 / 練習 / 笑
- 祥子的回憶斷裂(失焦):祥子接電話 / 掛電話 / 走出 Live House
- 燈的歌聲:越來越輕,越來越遠
- 旁觀者視角:燈的影子 = 企鵝輪廓 → 開始模糊
- 祥子:「(回神)你……你的影子——」
- 燈:「(笑)嗯。我知道了。」
- 燈:「(對祥子)我以為……我唱完,她們就會回來。」
- 燈:「但是她們不會回來了。對嗎?」
- 祥子:「……不會。」

**選項**:
- → 2.6: 燈決定消失(企鵝回去她的世界)
- → 2.6: 燈決定留下(企鵝的代價)

---

### Scene 2.6: 「在場」(8 分鐘)
**POV**:旁觀者
**視覺**:回到正常色彩 + 灰階
**內容**:
- 燈:「(對旁觀者)你呢?你要去哪裡?」
- 旁觀者:無對白
- 燈:「(歪頭)我覺得……你不是偶然來的。」
- 燈:「你是來……看見的。」
- 旁觀者:無對白
- 燈:「(笑)那……我讓你多看一個東西。」
- 燈指向窗外:祥子在練習鍵盤(獨自)
- 燈:「她會繼續的。」
- 燈:「(對旁觀者)謝謝你。」
- 燈:「(對旁觀者)再見。」
- 燈走向月光,輪廓越來越模糊
- 燈消失(不是離開,是蒸發)

**選項**:無,直接進入 Scene 2.7

---

### Scene 2.7: 「空屋頂」(5 分鐘)
**POV**:旁觀者
**視覺**:灰階 + 輕微失真
**內容**:
- 旁觀者獨自站在 Live House 屋頂
- 環境:昨晚的樂器還在,沒人收
- 風聲 + 遠處祥子的鍵盤聲
- 旁觀者:無對白
- 旁觀者:拿起一片樂譜(燈寫的,但字跡不屬於人類)
- 旁觀者:放下
- 旁觀者:走下樓梯

**選項**:無,直接進入 Scene 2.8

---

### Scene 2.8: 「翌日」(4 分鐘)
**POV**:旁觀者 → 全景
**視覺**:灰階 → 彩色(結局色彩回歸)
**內容**:
- 旁觀者走出 Live House
- 路上:看到一群高中女生在聽音樂(MyGO!!!!! 單曲)
- 一個女生在哼【春日影】(旁觀者聽見,但女生不知道)
- 旁觀者:無對白
- 旁觀者:繼續走
- 鏡頭拉遠:Live House 屋頂,月光下,有企鵝輪廓的殘影
- 殘影消失
- 字幕:「迷茫也無妨。迷茫著,也要前進。」

**結局**:黑屏 → 通關畫面

## 寫作約束(全場景適用)

1. **不打問號 = 場景未完成**(本 PR 範圍只到 Scene 2.4 + 占位 2.5-2.8)
2. **旁觀者無對白**
3. **BGM 切換點 = 場景開頭 / 結尾 / 選項彈出時**
4. **打字機速度 = 30ms/字,空格 = 全部顯示**
5. **場景長度 = 字數 / 200 = 分鐘**
6. **每場景至少 1 個視覺提示**(灰階 / 失真 / 震動 / 彩色)
