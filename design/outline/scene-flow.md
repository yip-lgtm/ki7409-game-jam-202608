# 場景流程大綱 — 迷茫即是前進(高松燈篇)

*總時長 90 分鐘(20 + 60 + 10)*
*玩家 = 高松燈(企鵝版, 第一人稱)*
*Common Route → 高松燈線 → 尾聲*
*角色全部用原作真名*

---

## Part 0: Title & Boot(1 分鐘)

### Scene 0.1: 標題畫面
- 背景:夜空 + 月亮 + Live House 屋頂輪廓
- 文字動畫:標題從上往下浮現
- **標題**:**「迷茫即是前進」**
- **副標題**:**「— 高松燈(企鵝版)篇 —」**
- 企鵝立繭(neutral)中央(人頭 + 企鵝身)
- 玩家可點企鵝切換表情
- 按鈕:開始 / 設定 / 語言切換(繁/簡)

## Part 1: Common Route(20 分鐘,5 場景)

### Scene 1.1: 「你是高松燈」(3 分鐘)
**POV**:高松燈(玩家 = 第一人稱「你」)
**背景**:Live House 屋頂, 夜

**內容**:
- 玩家(企鵝版高松燈)醒來
- 8 個真名 NPC 圍著:長崎爽世(調音) / 椎名立希(敲鼓) / 豐川祥子(打電話) / 千早愛音(不知所措) / 若葉睦(跟著祥子) / 三角初華(和海鈴聊天) / 八幡海鈴(沒表情) / 祐天寺若麥(自拍)
- 長崎爽世:「高松燈——你願意當主唱嗎?」
- 玩家(高松燈)歪頭, 不理解
- UI 揭示:「**你是高松燈。CRYCHIC 的主唱。**」(你不知道這意味著什麼)

**選項**(第一個選擇):
- → 1.2: 「(沉默)……」(沉默, 觀望)
- → 1.2: 「(我……我試試。)」(接受, 嘗試唱歌)
- → 1.2: 「(我不懂……但我——)」(困惑, 但願意)

---

### Scene 1.2: 「第一次唱」(3 分鐘)
**POV**:玩家
**FX**:彩色

**內容**:
- 玩家張嘴, 唱出第一個音
- **不是歌, 是節拍** —— 對上了椎名立希的鼓
- 椎名立希:「(停下鼓棒)……你會跟節奏?」
- 玩家(高松燈):「(歪頭)節奏?」
- 豐川祥子:「(掛電話, 掃一眼)——企鵝?」
- 玩家(高松燈):「(歪頭)企鵝……?」(第一次有人這麼稱呼她)
- 長崎爽世:「(小聲)她就是這樣。別在意。」

**UI 揭示**:**「你剛才唱的是:節奏 X」(BPM 120, 不是歌, 只是節拍)**

**結局**:選項
- → 1.3: 走向長崎爽世(她對你最溫柔)
- → 1.3: 走向豐川祥子(她最危險, 但似乎知道什麼)
- → 1.3: 走向窗邊(遠離人群, 思考「企鵝」是什麼意思)

---

### Scene 1.3: 「主唱是什麼?」(5 分鐘, 關鍵場景)
**POV**:玩家
**FX**:彩色

**內容**:
- 長崎爽世:「高松燈——一起唱吧。你是主唱。」
- 玩家(高松燈):「(歪頭)主唱?」
- 長崎爽世:「就是——開口, 發出聲音, 讓大家聽。」
- 玩家(高松燈):「(張嘴)……」(嘗試)
- 所有人看著玩家
- 玩家(高松燈):「(張嘴)——」(繼續嘗試)

**關鍵選擇**(本場景最重要):
- → 1.4: 唱「春日影(變奏)」(完整的歌)
- → 1.4: 唱「壱雫空」(另一首)
- → 1.4: 不唱(不開口)

**UI 揭示**:根據選擇揭示
- 春日影 → 揭示「你剛才唱的是:春日影(變奏)」
- 壱雫空 → 揭示「你剛才唱的是:壱雫空」
- 不唱 → 揭示「你什麼都沒唱」

---

### Scene 1.4: 「解散夜」(7 分鐘, 本路線高潮)
**POV**:玩家
**FX**:玩家唱春日影時 = 彩色(全劇唯一彩色)
**關鍵**:玩家唱春日影後, 所有人崩潰

**內容**:
- 玩家唱春日影(打字機 + 揭示):【迷失也無妨。迷失著, 也要前進……】
- 豐川祥子:「——」(掛電話)
- 長崎爽世:「(站起來)你——你怎麼會唱這首?」
- 椎名立希:「(停下鼓棒)」
- 千早愛音:「(愣住)」
- 若葉睦:「(看著你)」
- 三角初華:「(收起笑容)」
- 八幡海鈴:「(沒說話)」
- 祐天寺若麥:「(放下手機)」
- 豐川祥子:「CRYCHIC 的排練, 到這裡。」
- (解散的話, 跟原作類似, 但這次是玩家見證)

**結局**:**黑屏 + 文字**「翌日」

**玩家選擇**(必選):
- → 2.1: 玩家選擇**留下**(「我不走。咕。」——等等, 不用咕)**(「我不走。」)** —— 進入高松燈線
- → 2.1: 玩家選擇**飛走**(展開翅膀, 離開)—— 本 PR 跳過, 回標題

## Part 2: 高松燈線(60 分鐘,8 場景)

### Scene 2.1: 「你的影子」(5 分鐘)
**POV**:玩家
**FX**:彩色

**內容**:
- 翌日, 玩家在 Live House 後巷
- 玩家第一次仔細看自己的影子
- **影子是企鵝輪廓**(黑背白肚, 短腳)
- 玩家(高松燈):「(歪頭)……這是誰?」
- 玩家觸碰自己:摸到羽毛
- 玩家(高松燈):「(張嘴)……羽毛?」
- **玩家第一次意識到:自己好像不是人**

**選項**:
- → 2.2: 走向 Live House(回到屋頂)
- → 2.2: 走向車站(離開這個世界)

---

### Scene 2.2: 「屋頂的回憶」(8 分鐘)
**POV**:玩家
**FX**:彩色 → 灰階(觸發回憶)

**內容**:
- 玩家回到昨晚的屋頂
- 樂器還在, 沒人收
- 玩家觸碰鍵盤(豐川祥子的):回憶 → 灰階 → 祥子在彈, 回憶斷裂
- 玩家觸碰吉他(長崎爽世的):回憶 → 灰階 → 爽世在唱, 回憶斷裂
- 玩家(高松燈):「(張嘴)——」
- **UI 揭示**:**「你剛才唱的是:壱雫空」**
- 玩家(高松燈):「(歪頭)壱……雫空?」
- 這是玩家**第一次意識到**自己會唱「歌」

**選項**:
- → 2.3: 玩家去找長崎爽世(她最可能解釋)
- → 2.3: 玩家繼續在屋頂(自己探索)

## 寫作約束(全場景適用)

1. **不打問號 = 場景未完成**(本 PR 範圍只到 Scene 1.4 + Scene 2.1-2.2)
2. **玩家 = 第一人稱「你」**
3. **NPC 稱呼玩家 = 「高松燈」**(有重量, 因為是企鵝)
4. **歌名揭示必須延遲 0.5 秒**
5. **打字機 30ms/字**
6. **場景長度 = 字數 / 200 = 分鐘**
7. **每場景至少 1 個 FX**
8. **8 首歌的嵌入點必須明確**
