# 場景流程大綱 — 你是湊企鵝,你是誰啊?

*總時長 90 分鐘(20 + 60 + 10)*
*玩家 = 湊企鵝(主唱, 第一人稱)*
*Common Route → 主唱線 → 尾聲*

---

## Part 0: Title & Boot(1 分鐘)

### Scene 0.1: 標題畫面
- 背景:夜空 + 月亮 + Live House 屋頂輪廓
- 文字動畫:標題從上往下浮現
- **標題**:**「你是湊企鵝,你是誰啊?」**
- 按鈕:開始 / 設定 / 語言切換(繁/簡)
- 企鵝立繪(neutral)中央
- 玩家可點企鵝觸發「咕咕嘎嘎」彩蛋

---

## Part 1: Common Route(20 分鐘,5 場景)

### Scene 1.1: 「你是誰?」(3 分鐘)
**POV**:湊企鵝(玩家 = 第一人稱「你」)
**背景**:Live House 屋頂,夜
**玩家剛醒來**

**內容**:
- 玩家 = 企鵝,站在屋頂中央
- 8 個人圍著(吉他手 A 在調音,鼓手 A 在敲鼓,鍵盤手 A 在窗邊打電話,主音吉他 A 在旁邊不知所措,吉他手 B 跟著鍵盤手 A,主唱 B 在和貝斯手 B 聊天,鼓手 B 在自拍)
- 玩家(企鵝)歪頭,**不知道自己為什麼在這**
- 吉他手 A 注意到玩家:「你是——新來的主唱?」
- 玩家 UI 揭示:「**你還沒有名字。** 你是湊企鵝。」

**選項**(這是玩家**第一個選擇**):
- → 1.2: 「咕。」(接受,玩家張嘴發出咕的聲音,大家驚訝)
- → 1.2: 「嘎?」(疑惑,玩家歪頭,吉他手 A 笑)
- → 1.2: 「咕咕嘎嘎。」(玩梗,主唱 B 笑翻,鼓手 B 立刻拍)

---

### Scene 1.2: 「咕」(3 分鐘)
**POV**:玩家(企鵝)
**FX**:彩色(全劇開始就是彩色,因玩家 = 主體)

**內容**:
- 玩家張嘴,發出「咕」的聲音
- 吉他手 A:「再唱一次。」
- 玩家:「咕。」
- 鼓手 A 敲鼓,節奏對上了
- **玩家 UI 揭示**:**「你剛才唱的是:節奏 X」(BPM 對, 但不是歌,只是節拍)**
- 鍵盤手 A 掛電話:「(掃一眼)——企鵝?」
- 玩家:「(歪頭)咕?」
- 鍵盤手 A 沒回應,繼續打電話
- 吉他手 A:「(小聲)她就是這樣。別在意。」

**結局**:選項
- → 1.3: 玩家走向吉他手 A(她對玩家最溫柔)
- → 1.3: 玩家走向鍵盤手 A(她最危險)
- → 1.3: 玩家走向窗邊看月亮(最遠離人群)

---

### Scene 1.3: 「她們在排什麼?」(5 分鐘,關鍵場景)
**POV**:玩家
**FX**:彩色

**內容**:
- 玩家選擇後接近某個 NPC
- **關鍵:這個 NPC 開始排練,玩家被要求「主唱」**
- 吉他手 A:「一起唱吧。你是主唱。」
- 玩家:「主唱?」
- 吉他手 A:「(笑)就是唱歌。」
- 玩家:「(歪頭)咕?」(意思是「唱歌是什麼?」)
- 吉他手 A 給玩家解釋:「就是——開口,發出聲音,讓大家聽。」
- 玩家:「(張嘴)咕。」
- **所有人看著玩家**
- 玩家:「(張嘴)咕咕——」

**關鍵選擇**(本場景最重要):
- → 1.4: 玩家唱「春日影(變奏)」(咕咕嘎嘎完)
- → 1.4: 玩家唱「壱雫空」(另一首)
- → 1.4: 玩家拒絕,「嘎。」(不想唱)

**UI 揭示**:根據選擇,玩家在選擇時不知道自己唱了什麼。**選擇後揭示**:
- 選「春日影」→ 揭示「你剛才唱的是:春日影(變奏)」
- 選「壱雫空」→ 揭示「你剛才唱的是:壱雫空」
- 選「拒絕」→ 揭示「你什麼都沒唱」

---

### Scene 1.4: 「解散夜」(7 分鐘,本路線高潮)
**POV**:玩家
**FX**:玩家唱春日影時 = 彩色(全劇唯一彩色)
**關鍵**:玩家唱春日影後,所有人崩潰

**內容**:
- 玩家唱春日影(打字機 + 揭示):【迷失也無妨。迷失著,也要前進……】
- 鍵盤手 A:「——」(掛電話)
- 吉他手 A:「(站起來)你——你怎麼會唱這首?」
- 鼓手 A:「(停下鼓棒)」
- 主音吉他 A:「(愣住)」
- 吉他手 B:「(看著玩家)」
- 主唱 B:「(收起笑容)」
- 貝斯手 B:「(沒說話)」
- 鼓手 B:「(放下手機)」
- 鍵盤手 A:「CRYCHIC 的排練,到這裡。」
- (解散的話,跟原作類似,但這次是玩家見證)

**結局**:**黑屏 + 文字**「翌日」

**玩家選擇**(必選):
- → 2.1: 玩家選擇**留下**(「咕。」)—— 進入主唱線
- → 2.1: 玩家選擇**飛走**(展開翅膀,離開)—— 本 PR 跳過,回標題

---

## Part 2: 主唱線(60 分鐘,8 場景)

### Scene 2.1: 「你的影子」(5 分鐘)
**POV**:玩家(企鵝,第一人稱)
**FX**:彩色

**內容**:
- 翌日,玩家在 Live House 後巷
- 玩家第一次看自己的影子
- **影子是企鵝輪廓**(黑背白肚, 短腳)
- 玩家:「(歪頭)咕?」
- 玩家觸碰自己:摸到羽毛
- 玩家:「(張嘴)咕咕嘎嘎。」
- **玩家還是不理解,但記住了「我好像是——」**

**選項**:
- → 2.2: 玩家走向 Live House(回到屋頂)
- → 2.2: 玩家走向車站(離開這個世界)

---

### Scene 2.2: 「屋頂的回憶」(8 分鐘)
**POV**:玩家
**FX**:彩色 → 灰階(觸發回憶)

**內容**:
- 玩家回到昨晚的屋頂
- 樂器還在,沒人收
- 玩家觸碰鍵盤(鍵盤手 A 的):回憶 → 灰階 → 鍵盤手 A 在彈,回憶斷裂
- 玩家觸碰吉他(吉他手 A 的):回憶 → 灰階 → 吉他手 A 在唱,回憶斷裂
- 玩家:「(張嘴)咕。」
- **UI 揭示**:**「你剛才唱的是:壱雫空」**
- 玩家:「(歪頭)壱……雫空?」
- 這是玩家**第一次意識到**自己會唱「歌」

**選項**:
- → 2.3: 玩家去找吉他手 A(她最可能解釋)
- → 2.3: 玩家繼續在屋頂(自己探索)

---

### Scene 2.3: 「吉他手 A 的房間」(10 分鐘)
**POV**:玩家
**FX**:彩色

**內容**:
- 玩家找到了吉他手 A
- 吉他手 A:「你……怎麼找到我的?」
- 玩家:「咕。」
- 吉他手 A:「(沉默)進來。」
- 屋內:吉他很多,牆上貼著「CRYCHIC」海報(玩家不理解這是什麼)
- 吉他手 A:「你想學唱歌?」
- 玩家:「(歪頭)學?」
- 吉他手 A:「就是——練習。」
- 玩家:「(張嘴)咕咕嘎嘎。」(玩家**唱**)
- **UI 揭示**:**「你剛才唱的是:壱雫空(完整版)」**
- 吉他手 A:「(流淚)你——你怎麼會——」(她以為只有自己會這首)
- 玩家:「(歪頭)嘎?」(不理解她為什麼哭)

**選項**:
- → 2.4: 玩家走向吉他手 A(安慰)
- → 2.4: 玩家張開翅膀(飛走)

---

### Scene 2.4: 「我為什麼會唱?」(8 分鐘)
**POV**:玩家
**FX**:彩色 → 灰階(玩家觸碰回憶)

**內容**:
- 玩家走向吉他手 A,但不理解為什麼她哭
- 玩家觸碰吉他手 A 的吉他:回憶 → 吉他手 A 在排練,笑著
- 玩家:「(張嘴)咕。」
- **UI 揭示**:**「你剛才唱的是:迷星叫(MyGO!!!!! 第二張單曲)」**
- 吉他手 A:「這首——你不該會——這是——」(她以為這是她們的私房歌)
- 玩家:「(歪頭)我不該?」
- 吉他手 A:「(沉默很久)……也許你該會。」

**選項**:
- → 2.5: 玩家唱春日影(給吉他手 A 聽)
- → 2.5: 玩家離開(不打擾)

---

### Scene 2.5: 「春日影給你」(10 分鐘,本路線情感高峰)
**POV**:玩家
**FX**:灰階 → 彩色(玩家唱春日影時全劇唯一彩色)

**內容**:
- 玩家:「(張嘴)」
- 玩家唱春日影(變奏,打字機):
  - 【迷失也無妨。】
  - 【迷失著,也要前進。】
  - 【即使在這條路上,看不見彼此。】
  - 【——春日影。】
- 吉他手 A:「(哭)」
- 玩家:「(歪頭)嘎?」(不理解她為什麼哭得更厲害)
- 吉他手 A:「這首歌——這是——」(她以為只有 CRYCHIC 的人會唱)
- 玩家:「(張嘴)咕咕嘎嘎。」(再唱一遍)
- 吉他手 A:「(抱著吉他)——再唱。」

---

### Scene 2.6: 「鼓手 A 在樓下」(5 分鐘)
**POV**:玩家
**FX**:彩色

**內容**:
- 玩家從吉他手 A 家出來
- 樓下,鼓手 A 在抽煙(她不抽菸,只是拿著)
- 鼓手 A:「(沒看玩家)」
- 玩家:「咕。」
- 鼓手 A:「(抬頭)——」(她第一次看玩家)
- 鼓手 A:「你……是昨晚那個。」
- 玩家:「(歪頭)昨晚?」
- 鼓手 A:「(沒回答,站起來)」
- 她走向 Live House,玩家跟著

**選項**:
- → 2.7: 玩家跟著鼓手 A
- → 2.7: 玩家留下

---

### Scene 2.7: 「Live House 再見」(8 分鐘)
**POV**:玩家
**FX**:彩色

**內容**:
- 鼓手 A 回到 Live House
- 她在鼓組前坐下
- 鼓手 A:「(敲鼓)三、二、一——」
- 玩家:「(張嘴)咕。」
- 鼓手 A:「(停)你——」
- 玩家:「(張嘴)咕咕嘎嘎。」
- **UI 揭示**:**「你剛才唱的是:影色舞(Ave Mujica 第四張單曲)」**
- 鼓手 A:「(愣住)你會 Ave Mujica 的歌?」
- 玩家:「(歪頭)Ave? Mujica?」(不理解)
- 鼓手 A:「——」(她第一次不說話)

**選項**:
- → 2.8: 玩家唱春日影給鼓手 A
- → 2.8: 玩家飛走(不想待在這)

### Scene 2.8: 「後巷的決定」(6 分鐘)
**POV**:玩家
**FX**:彩色(全劇結尾回歸彩色)

**內容**:
- 玩家從 Live House 出來,走到後巷
- 玩家:「(看自己的影子)我——是什麼?」
- **玩家第一次問自己「我是什麼」**
- 玩家:「(張嘴)咕。」
- **UI 揭示**:**「你剛才唱的是:栞(MyGO!!!!! 第三張單曲)」**
- 玩家:「(張嘴)咕咕嘎嘎。」(再唱)
- **UI 揭示**:**「你剛才唱的是:栞(完整版)」**
- 玩家:「(歪頭)我是——企鵝。」
- **玩家終於意識到自己是企鵝**
- 玩家:「(張嘴)但我會唱。」
- 玩家:「(張開翅膀)」
- **選項**(結局選擇):
  - → 結尾 A:「(飛走)咕。」(玩家選擇離開這個世界)
  - → 結尾 B:「(留下)咕咕嘎嘎。」(玩家選擇留下,繼續唱)

## 寫作約束(全場景適用)

1. **不打問號 = 場景未完成**(本 PR 範圍只到 Scene 1.4 + Scene 2.1-2.2)
2. **玩家 = 第一人稱「你」**
3. **歌名揭示必須延遲 0.5 秒**
4. **打字機 30ms/字**
5. **場景長度 = 字數 / 200 = 分鐘**
6. **每場景至少 1 個 FX**(彩色/灰階/震動)
7. **8 首歌的嵌入點必須明確**
