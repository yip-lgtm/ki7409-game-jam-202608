## 設定

- **人頭**:原作高松燈的髮型(短黑髮, 中等長度, 齊劉海)
- **企鵝身**:白肚 / 黑背 / 橙腳
- **表情**:4 種 CSS 切換(neutral / shout / sad / sing)
- **聲音**:第一人稱短句, 結尾不打問號

## 玩家不知道的事

- 自己是企鵝(透過「影子的形狀」「羽毛的觸感」慢慢發現)
- 自己會唱所有歌(透過 UI 揭示才發現)
- 自己在別人眼中是「奇怪的企鵝版高松燈」

## 玩家知道的事

- 自己叫高松燈
- 自己在 Live House 屋頂
- 8 個人在周圍, 各自在幹什麼
- 有人要你「唱歌」

## 對白規則(玩家)

### 第一人稱

- 「你」/「高松燈」交替(其他角色叫她「高松燈」)
- 短句為主(不超過 15 字)
- 主詞常省略
- 結尾不打問號(用「……」)

### 範例玩家對白(其他角色對她說的)

> 「高松燈——你怎麼還在這?」
> 「(高松燈的名字)你不記得了嗎?」
> 「(對她)再唱一次。」

### 範例玩家內心 / 行動

> 「(你站著。)」
> 「(你不知道自己為什麼在這。)」
> 「(你舉起手——但手有羽毛。)」

### 玩家選項

- **「留下」/「我不走」**:接受, 留在此刻
- **「離開」/「我想走」**:拒絕, 走開
- **「……」**:沉默(不確定, 觀望)

## UI 揭示機制

- 玩家選完後 0.5 秒延遲, UI 顯示「你剛才唱的是:XX」
- 揭示只在每首歌**第一次**唱時顯示
- 玩家**事後**才意識到自己會唱

## 寫作約束

- 不解釋為什麼是企鵝(設定)
- 不解釋為什麼會唱所有歌(設定)
- 玩家視角 = 第一人稱「你」/ 第三人稱「高松燈」(其他人稱呼)

## 為什麼立繭是「人頭 + 企鵝身」

**社群 meme「湊企鵝」原型**:
- bilibili 2025 二創
- 「高松燈的頭 + 企鵝的身體」
- 我們**保留人頭 + 企鵝身的視覺**, 但**不保留咕咕嘎嘎叫聲**
