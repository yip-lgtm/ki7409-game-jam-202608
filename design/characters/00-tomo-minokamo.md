# 角色:湊企鵝(玩家)

> **玩家 = 湊企鵝 = 神主唱**
> **不知道自己是企鵝。**
> **不知道自己會唱所有歌。**

## 設定

社群 meme 形象:
- **身體**:企鵝(黑背白肚,橙色腳蹼)
- **頭**:短髮女生(深灰色漸層髮,中等長度)
- **表情**:4 種 CSS 切換(neutral / shout / sad / sing)
- **聲音**:咕 / 嘎 / 咕咕嘎嘎(無意義音節)

## 玩家不知道的事

- 自己是企鵝(透過「影子的形狀」「羽毛的觸感」慢慢發現)
- 自己會唱所有歌(透過 UI 揭示才發現)
- 自己在別人眼中是「奇怪的企鵝主唱」
- 別人在崩潰(透過視覺 FX 才發現)

## 玩家知道的事

- 自己叫湊企鵝(這是「名字」,但不知道是誰給的)
- 自己在 Live House 屋頂
- 8 個人在周圍,各自在幹什麼
- 有人要你「唱歌」

## 對白規則

### 玩家自選對白
- 短句為主(不超過 10 字)
- 主詞常省略
- 結尾常見「咕 / 嘎」(感嘆號替代)
- 不用「我」自稱,直接說動作

### 範例玩家對白
> 「咕。」
> 「嘎嘎?」
> 「咕咕嘎嘎。」
> 「(唱歌)【……那個歌。】」
> 「再唱。」

### 玩家選項
- 「咕」:平靜, 接受
- 「嘎」:反駁, 探問
- 「咕咕嘎嘎」:不確定, 玩梗

## UI 揭示機制

- 玩家選完後 0.5 秒延遲,UI 顯示「你剛才唱的是:《XX》」
- 玩家沒看到就推進,看 UI 提示才意識到自己會唱
- 揭示只在每首歌**第一次**唱時顯示,後續不再提示

## 寫作約束

- 不解釋企鵝來源
- 不解釋神主唱來源
- 不解釋為什麼 8 個人在這裡
- 玩家視角 = 第一人稱
- 「你」在文本中 = 玩家 = 企鵝
